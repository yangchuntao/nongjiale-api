# 一、游客 `MP-`

## MP-HOME 首页

| 项 | 内容 |
|----|------|
| 用户与主任务 | 游客；在微信内发现活动（Banner）、进入找店或攻略、拨打客服 |
| 入口 | 小程序启动默认 Tab；分享回首页；其他页回 Tab |
| 出口 | MP-LIST、MP-GUIDE-LIST、MP-DETAIL（经 Banner 站内）、MP-WEBVIEW 或复制弹层、tel 客服 |

**布局与字段**

```
状态栏 + 导航（站名占位）
└─ 【Banner 区】0 条不渲染；1 静帧；≥2 轮播+指示点
└─ 找店入口卡（主）：文案「找苏中农家乐」→ MP-LIST
└─ 攻略入口卡（次）：「出行攻略」→ MP-GUIDE-LIST
└─ 客服电话条：配置电话，可点拨打（tel）
└─ （可选）轻量推荐店卡：若接口有，同 Web 推荐规则；无则不做，不挡验收
└─ 底栏 Tab：首页 | 找店 | 我的
```

**Banner 区（对齐 MVP-1.5）**

| 元素 | 说明 |
|------|------|
| 主视觉图 | 运营配置；失败占位 |
| 整卡热区 | 整图可点 |
| 指示点 | 仅 ≥2；当前帧 Brand |
| 角标 | **默认不做**「广告/赞助」 |

展示集：仅启用；ALL 不受市 Chip；CITY 仅 OPEN；sortOrder 越小越前。

**操作与反馈**

| 操作 | 反馈 |
|------|------|
| 点 Banner（站内） | navigateTo / redirectTo 目标页 |
| 点 Banner（外链，域名已配） | → MP-WEBVIEW |
| 点 Banner（外链，不可 web-view） | 弹层「复制链接」；成功 Toast「已复制，请到浏览器粘贴打开」 |
| 点找店 | → MP-LIST |
| 点攻略 | → MP-GUIDE-LIST |
| 点客服电话 | 调起拨号 |
| Banner 接口失败 | **静默隐藏** Banner 区 |

**六态**

| 态 | 表现 |
|----|------|
| 默认 | 按 Banner 条数展示；找店/攻略/电话可见 |
| loading | Banner 可选短骨架；入口卡可先出 |
| empty（Banner=0） | 隐藏 Banner；其余正常（不显示「暂无广告」） |
| error | Banner 失败静默隐藏；整页致命错误少见，可 Toast「加载异常」+ 重试 |
| 无权限 | N/A（公开） |
| 校验失败 | N/A |
| 小屏/安全区 | 满宽 Banner；底栏避让 Home Indicator；顶避让刘海 |

**关键文案：** 找店入口「找苏中农家乐」；攻略「出行攻略」；无支付/商家入驻入口。

## MP-LIST 找店列表

| 项 | 内容 |
|----|------|
| 用户与主任务 | 游客；在 OPEN 市中按市与关键词找到可看门店 |
| 入口 | 底栏「找店」；首页找店入口；Banner 站内到列表 |
| 出口 | MP-DETAIL；清空条件重筛 |

**布局与字段**

1. **筛区（本包必做 · Q2）**  
   - **市**：Select / Chip，**仅 OPEN 市**；默认第一个 OPEN 或「全部已开通市」（工程与产品可定默认；须保证 CLOSED 不可选）。  
   - **关键词**：搜索框，占位「店名/关键词」。  
   - 可选（不挡验收）：简单排序（综合）；**不做**价格支付类筛。

2. **列表行/卡**  
   - 封面图、店名、市/区摘要、一句话卖点或套餐摘要、电话可展示为次要。  
   - 整卡可点进详情。

3. **底栏** 找店选中。

**操作与反馈**

| 操作 | 反馈 |
|------|------|
| 切换市 | 刷新列表；分页重置 |
| 关键词搜索/清空 | 刷新列表 |
| 点卡片 | → MP-DETAIL |
| 下拉刷新 / 触底加载 | 常规列表反馈 |
| 深链 CLOSED 市 | 提示「该市暂未开通」并回退合法市；**不展示脏数据** |

**六态**

| 态 | 表现 |
|----|------|
| 默认 | 筛区 + 列表 |
| loading | 列表骨架 |
| empty | 「该市暂无上架农家乐」或「未找到相关门店」+ 引导改市/改词 |
| error | 「列表加载失败，请重试」 |
| 无权限 | N/A |
| 校验失败 | N/A（筛无整表提交） |
| 小屏/安全区 | 单列卡；筛区吸顶；底栏安全区 |

**关键文案：** 不出现 CLOSED 市名作可选供给；无「立即支付预订」。

## MP-DETAIL 门店详情（含分享）

| 项 | 内容 |
|----|------|
| 用户与主任务 | 游客；看懂图文/电话/套餐与须知，决定提交意向或分享 |
| 入口 | 列表、首页推荐、分享卡片、Banner 站内 |
| 出口 | MP-INTENT-FORM（已登录）/ MP-LOGIN（未登录）；tel；分享调起；返回列表 |

**布局与字段**

- 图集（横滑；alt≈店名）  
- 店名、地址、**门店电话**（可拨打）  
- **套餐 / 须知摘要**（对齐 Web 详情信息结构的只读摘要）  
- 非锁房轻提示条（Brand Soft 底）：「意向不等于已锁房」  
- **主 CTA：提交意向**（副文：「客服确认后安排，非即时订成」）  
- **分享按钮**（明确入口；另支持胶囊转发）  
- 次 CTA：拨打电话  
- **无定金/支付按钮**  
- 底栏隐藏；底部可固定 CTA 条（避让安全区）

**操作与反馈**

| 操作 | 反馈 |
|------|------|
| 提交意向（未登录） | → MP-LOGIN，成功后进意向表（带 listingId） |
| 提交意向（已登录且可订） | → MP-INTENT-FORM |
| 提交意向（下架/不可订） | CTA 禁用或 Toast「该房源暂不可提交意向」 |
| 分享 | 调起微信分享卡片（见文末「分享卡片字段建议」） |
| tel | 系统拨号 |
| 分享打开无效店 | 页级「已下架或不可用」；隐藏提交 |

**六态**

| 态 | 表现 |
|----|------|
| 默认 | 完整详情 + CTA + 分享 |
| loading | 页骨架 |
| empty | N/A（无 id → error） |
| error | 「加载失败，请重试」 |
| 无权限 | N/A（公开可读） |
| 校验失败 | N/A |
| 小屏/安全区 | 图集横滑；底栏 CTA 固定 + safe-area |
| **不可订/下架** | 主 CTA 禁用；文案「该房源暂不可提交意向」；仍可浏览/拨打（若电话仍展示） |

**关键文案：** 「提交意向 · 客服将联系确认 · 意向不等于已锁房」

## MP-LOGIN 微信登录 / 补全手机号

| 项 | 内容 |
|----|------|
| 用户与主任务 | 游客；完成微信授权及必要手机号补全，以便提交意向或查看我的意向 |
| 入口 | 提交意向拦截、我的意向拦截、底栏「我的」未登录 |
| 出口 | redirect 原目标（意向表 / 详情 / 我的意向）；失败留页 |

**布局与字段**

1. **步骤 A · 微信授权**  
   - 品牌区：站名 + 一句「登录后提交意向，客服将联系您」  
   - Primary：「微信一键登录」（按当前微信能力实现）  
   - 次要：「暂不登录」→ 回上一页或首页  

2. **步骤 B · 补全手机号（UI 留位，工程定）**  
   - 说明：「为与网页版账号打通 / 便于客服联系，请补全手机号」（文案按打通方案微调）  
   - 控件：微信手机号快速验证按钮 **或** 手机号 + 验证码表单（工程二选一）  
   - Primary：「确认」  
   - 若产品允许稍后补全：Secondary「稍后再说」（**不得**在未完成打通要求时假装意向已同步）

**操作与反馈**

| 操作 | 反馈 |
|------|------|
| 授权成功且无需补全 | Toast「登录成功」→ redirect |
| 授权成功需补全 | 进入步骤 B |
| 补全成功 | Toast「登录成功」→ redirect |
| 授权失败/拒绝 | Toast「需要授权后才能提交意向」；留页 |
| 已登录误入 | 重定向首页或 redirect |

**六态**

| 态 | 表现 |
|----|------|
| 默认 | 步骤 A 或 B 表单 |
| loading | 按钮 loading，防重复 |
| empty | N/A |
| error | 网络/服务 Toast |
| 无权限 | 已登录则重定向 |
| 校验失败 | 手机号格式等字段红字 |
| 小屏/安全区 | 单列居中；按钮满宽避让底部安全区 |

**关键文案：** 不出现第三方支付登录；成功「登录成功」。打通未完成时，进入「我的」须遵守 DESIGN §5.3，不得伪造 Web 同步。

## MP-INTENT-FORM 提交意向

| 项 | 内容 |
|----|------|
| 用户与主任务 | 已登录游客；填写并提交意向 |
| 入口 | 详情 CTA（须登录） |
| 出口 | MP-INTENT-SUCCESS；或失败留表 |

**布局与字段**

- 顶 Banner（**必显**）：「提交意向后，客服会联系您确认。**意向不等于已锁房。**」  
- 只读：门店名、关键价/套餐摘要（若有）  
- 表单：到店日、离店日**或**晚数、人数、联系人姓名、手机（默认可带账号手机）、备注可选  
- Primary：「提交意向」  
- **无支付字段、无定金勾选**

**操作与反馈**

| 操作 | 反馈 |
|------|------|
| 提交成功 | → MP-INTENT-SUCCESS（带单号） |
| 409 / 不可订 | 页级错误，不跳转，不产生有效单 |
| 410 / 下架 | 同上 + 建议回列表 |
| 返回 | 回详情 |

**六态**

| 态 | 表现 |
|----|------|
| 默认 | 表单 + 非锁房 Banner |
| loading | 提交中禁用按钮 |
| empty | 店信息失败按 error |
| error | 创建失败明确文案 |
| 无权限 | 未登录 → MP-LOGIN |
| 校验失败 | 日期逻辑、人数、手机、姓名必填红字 |
| 小屏/安全区 | 单列；日期用小程序选择器；底按钮安全区 |

**关键文案：** 「提交后客服会电话联系您确认档期与接待安排。**提交意向不等于已锁房。**」

## MP-INTENT-SUCCESS 意向成功

| 项 | 内容 |
|----|------|
| 用户与主任务 | 游客；确认已交意向并知悉下一步（未锁房） |
| 入口 | 意向表提交成功 |
| 出口 | MP-MY-INTENTS、MP-HOME、tel 客服 |

**布局与字段（必须含）**

1. 成功图标 + 标题「意向已提交」  
2. **意向单号**（等宽/可复制）  
3. **客服电话**（配置，`tel:` 可拨）  
4. **「意向 ≠ 已锁房」** 说明（必显，不可折叠掉关键句）  
5. 摘要：店名、意向日期/人数  
6. 操作：Primary「查看我的意向」；Secondary「返回首页」；「拨打客服」

**操作与反馈**

| 操作 | 反馈 |
|------|------|
| 查看我的意向 | → MP-MY-INTENTS |
| 返回首页 | → MP-HOME（switchTab） |
| 拨打客服 | 调起拨号 |
| 复制单号 | Toast「已复制单号」 |

**六态**

| 态 | 表现 |
|----|------|
| 默认 | 成功信息完整展示 |
| loading | 若需拉单详情，短骨架 |
| empty | N/A |
| error | 若单号已有则仍展示并提示刷新；否则「提交结果获取失败，请到我的意向查看」 |
| 无权限 | 非本人 → 无权限提示 / 回首页 |
| 校验失败 | N/A |
| 小屏/安全区 | 单列；主按钮避让安全区 |

**关键文案（必须）：**  
「意向单号：{no}。客服电话：{phone}。  
我们会尽快联系您确认。**意向不等于已锁房，请勿理解为已订成或已支付。**」

# 二、分享卡片字段建议

| 字段 | 建议 |
