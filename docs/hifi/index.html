关键交互规则（来自 MVP-1.5 规格）

  • Banner 条数：0 条隐藏区块 · 1 条静帧无指示点 · ≥2 条轮播（约 5s 自动切，悬停/聚焦暂停）
  • 排序：按 sort 升序，数字越小越靠前；轮播起始为排序最前一条
  • 范围：全站（ALL）不受目的地 Chip / URL 市参影响；定向市须为 OPEN 才对客
  • 外链：http(s) 链接新标签页打开，带 noopener noreferrer；站内 / 开头同 tab
  • 文案禁区：不出现支付 / 买位 / 竞价 / 曝光计费；不出现强制「广告 / 赞助」角标；商家端无广告入口
  • 窄屏：Banner 满宽自适应 + 触滑，指示点保留；表格横滑或改卡片
