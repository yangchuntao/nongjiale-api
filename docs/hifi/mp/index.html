小程序端设计约束（来自 MVP-2 规格）

  • 禁绿色品牌：主色只用 #4BA3D9；绿色仅作「已入住」等状态 Tag，不用作品牌色
  • 底栏三 Tab：首页 / 找店 / 我的；攻略不进底栏，从首页入口进；非 Tab 页隐藏底栏
  • Banner：0 条不渲染 · 1 条静帧 · ≥2 轮播+指示点；外链优先 web-view，否则复制链接弹层
  • 非锁房：详情、意向表、成功页必显「意向不等于已锁房」，不可折叠掉关键句
  • 无支付：全路径无支付/定金/钱包；无商家运营配置入口
  • 状态 Tag：待跟进 / 已确认 / 已改期 / 已入住 / 已关闭；CHECKED_IN 只能用「已入住」
  • 安全区：顶避让刘海（44pt）、底避让 Home Indicator（34pt）；底栏与固定 CTA 均需避让
  • 分享：path 必须带 listingId，落地 MP-DETAIL；分享文案禁「已订成/支付/定金」
