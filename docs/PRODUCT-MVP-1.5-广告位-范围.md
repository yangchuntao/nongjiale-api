| 项 | 内容 |
|----|------|

## 2. 范围

### 2.1 本次要做

| # | 能力 | 说明 |
|---|------|------|
| A1 | **首页 Banner 展示（门户）** | 首页展示启用中的 Banner；多条时按排序展示（单帧或简单轮播均可，UI 定交互细节）。 |
| A2 | **运营后台配置** | 可配：图片、跳转链接（站内路径或 https 外链）、启用/停用、排序权重、投放范围（全站 / 指定市）。 |
| A3 | **按市投放** | 标「全站」→ 所有游客首页可见；标「仅某市」→ 仅当该市为 **OPEN** 时参与展示逻辑（见 §3）；**CLOSED 市不得作为有效定向**（或定向后不展示）。 |
| A4 | **启停即时生效** | 停用后首页不再展示该条；无需发版。 |

## 3. 业务规则

1. **投放方**：仅运营角色可增删改启停；游客只读展示；商家无配置入口。  
2. **展示位置**：仅门户**首页** Banner 区；一屏可展示条数与轮播由 UI 定，产品约束「只认启用且排序合法」的条目。  
3. **投放范围**  
   - `ALL`（全站）：首页可见，与当前所选目的地无关。  
   - `CITY`（指定市）：仅当该市 `openStatus=OPEN` 时该条可被选入展示集合；市为 CLOSED 或未配置时**不展示**该条。  
4. **排序**：数值越小（或越大，实现定一种并写清）越靠前；同序稳定即可。  
5. **链接**：支持站内相对路径与 http(s) 外链；外链建议新开页（UI 定）。无效链接不挡展示，点击失败由浏览器表现，不做一期校验弹窗强制。  
6. **无启用条目**：Banner 区折叠或隐藏，首页其余模块正常（不报错、不空白挡主路径）。  
7. **硬锁**：无支付/买位文案与入口；不改意向状态；CHECKED_IN=「已入住」。

## 4. 用户流程（摘要）

### 4.1 运营配置一条 Banner

1. 登录运营后台 → 广告位/Banner 管理。  
2. 新建：上传或填图、填链接、选全站或某 OPEN 市、设排序 → 启用。  
3. 打开门户首页 → 可见该 Banner；点击跳转目标页。

### 4.2 运营停用

1. 将该条设为停用 → 首页刷新后不再出现。

### 4.3 游客

1. 打开门户首页 → 见启用 Banner（若有）→ 可点进链接；无 Banner 时不影响找店/意向。

## 5. 验收标准（可测）

前置：测服门户首页与运营后台可达；至少一市 OPEN（如扬州）、一市 CLOSED（如南通）便于按市用例。

| ID | 前置 | 操作 | 可观察结果 |
|----|------|------|------------|
| **C-Ad1** | 运营可登录 | 配置一条**启用**、全站 Banner（有效图+链接） | 门户首页可见该图；点击进入所配链接 |
| **C-Ad2** | 已有启用 Banner | 运营将其**停用** | 首页刷新后不再展示该条 |
| **C-Ad3** | 至少两条启用、排序不同 | 打开首页 | 展示顺序与配置排序一致（或轮播起始序一致） |
| **C-Ad4** | 一条仅定向「扬州市」、一条仅定向 CLOSED「南通市」（或南通定向） | 打开首页 | 扬州定向在扬州为 OPEN 时可见；**南通 CLOSED 定向不出现** |
| **C-Ad5** | — | 巡检门户首页 + 运营广告配置页 + 商家端 | **无**支付/买位/钱包 CTA；意向与 CHECKED_IN「已入住」文案不变；商家无广告配置入口 |
