# 一、运营 `A-`（本包新增）

## A-BANNER Banner / 广告位列表

| 项 | 内容 |
|----|------|
| 用户与主任务 | 运营；浏览全部 Banner，启停、编辑、删除，并新建投放 |
| 入口 | 运营侧栏「广告位」或「Banner 管理」 |
| 出口 | A-BANNER-EDIT（新建/编辑）；列表内完成启停/删除后仍留本页 |

**布局与字段**

| 列 / 区块 | 说明 |
|-----------|------|
| 缩略图 | 约 120×48 或 16:9 小图；失败占位 |
| 标题或链接摘要 | 若有运营备注/标题则显示；否则截断展示链接（如 `/guides/xxx` 或域名） |
| 范围 Tag | 「全站」或「{市名}」；若定向市已 CLOSED，Tag 旁轻提示「市已关闭·不对客」 |
| 启用 Tag | 「启用」(success) / 「停用」(neutral) |
| 排序 | 整数；列表默认按此**升序**（小在前） |
| 操作 | 「编辑」Link；「启用」/「停用」Toggle 或按钮；「删除」Danger Text |

页头：标题「Banner 管理」+ Primary「新建 Banner」。

筛（可选）：启用状态（全部/启用/停用）、范围（全部/全站/按市）、关键词（链接或备注）。

**操作与反馈**

| 操作 | 反馈 |
|------|------|
| 新建 Banner | → A-BANNER-EDIT（空表） |
| 编辑 | → A-BANNER-EDIT（带数据） |
| 启用 | Toast「已启用」；Tag→启用；门户刷新后可见（若范围合法） |
| 停用 | Toast「已停用，首页将不再展示」；Tag→停用；门户不再展示该条 |
| 删除 | 确认弹窗 → 成功 Toast「已删除」；行移除 |
| 刷新 | 重新拉列表 |

**状态**

| 态 | 表现 |
|----|------|
| 默认 | 表或卡片列表，按 sort 升序 |
| loading | 表骨架 |
| empty | 「暂无 Banner，点击新建投放」+ CTA「新建 Banner」 |
| error | 「列表加载失败，请重试」 |
| 无权限 | 非运营 → 403 或回登录 |
| 校验失败 | N/A（列表无整表提交；启停失败用 Toast 错误） |
| 窄屏 | 表横滑或改卡片（缩略图+摘要+两 Tag+操作菜单） |

**关键文案：** 「仅影响门户首页 Banner；数字越小越靠前。全站投放与游客所选目的地无关。」

**删除确认文案：** 「删除后不可恢复，确认删除该 Banner？」

## A-BANNER-EDIT 新建 / 编辑 Banner

| 项 | 内容 |
|----|------|
| 用户与主任务 | 运营；录入或修改一条 Banner 的图、链接、范围、排序与启用状态并保存 |
| 入口 | A-BANNER「新建」或「编辑」；深链 `/admin/banners/new` · `/admin/banners/:id` |
| 出口 | 保存成功回列表（或留编辑页可再改）；取消回列表 |

**布局与字段**

1. **页头**  
   - 标题：「新建 Banner」或「编辑 Banner」  
   - 返回列表 Link  

2. **表单**

| 字段 | 控件 | 规则与说明 |
|------|------|------------|
| 图片 | 上传 **或** 图片 URL 输入（工程支持则二选一；至少一种可用） | **必填**；上传成功展示预览；URL 失焦可预览 |
| 链接 | 单行输入 | **必填**；站内以 `/` 开头，或 `http(s)://` 外链；旁注「外链将在新标签页打开」 |
| 投放范围 | Radio：全站 / 指定市 | **必选**；选「指定市」后出现市下拉 |
| 指定市 | Select（仅当范围=指定市） | **必选 OPEN 市**；CLOSED 市不出现，或 disabled + tip「该市未开通，不能作为投放目标」 |
| 排序 | Number | **必填**整数；默认建议 `100`；旁注「**数字越小越靠前**」 |
| 启用 | Switch | 新建默认开；关=停用，保存后不对客展示 |

3. **主操作区**  
   - Primary：「保存」  
   - Secondary：「取消」→ 回列表（有未保存变更可轻确认）  

**操作与反馈**

| 操作 | 反馈 |
|------|------|
| 保存（通过） | Toast「已保存」→ 回 A-BANNER（或可配置为留页） |
| 保存（校验失败） | 字段下红字；不提交 |
| 保存（后端拒绝，如 CITY 已 CLOSED） | 页级错误：「投放市未开通，请改选全站或其他已开通市」 |
| 取消 | 回列表 |
| 切换范围为全站 | 隐藏市下拉并清空已选市（或忽略） |
| 切换为指定市 | 展示 OPEN 市下拉 |

**状态**

| 态 | 表现 |
|----|------|
| 默认 | 表单 + 预览（若有图） |
| loading | 编辑态拉详情骨架；保存中按钮 loading、防重复 |
| empty | N/A（无 id 编辑走 error） |
| error | 详情加载失败「加载失败，请重试」；或保存网络错误 Toast |
| 无权限 | 非运营 → 403 |
| 校验失败 | 图未填：「请上传图片或填写图片地址」；链接未填：「请填写跳转链接」；CITY 未选市：「请选择已开通的市」；排序非整数：「请输入整数排序值」 |
| 窄屏 | 单列表单；预览图满宽 |

**关键文案：**

- 范围说明：「全站：所有游客首页可见，与目的地选择无关。指定市：仅该市为开通状态时展示。」  
- 禁区：表单与帮助文案**不出现**买位、竞价、曝光计费、支付。

# 二、门户 `P-`（相对 MVP-0/1 的增量）

> 完整首页规格仍以 `UI-PAGES-MVP-0.md` 为准；开城 Chip 规则见 `UI-PAGES-MVP-1-开城.md`。以下仅写广告位 **delta**。

## P-HOME 首页（delta · Banner 区）

| 项 | 内容 |
|----|------|
| 用户与主任务 | 游客；发现运营活动/引导并跳转；无 Banner 时不受阻地搜店与选目的地 |
| 入口 | `/` |
| 出口 | Banner 点击 → 站内同 tab 或外链新 tab；其余出口同 MVP-0/1 |

**布局位置（本包定稿）**

```
顶栏
└─ 【Banner 区】← 新增；0 条时整块不渲染
└─ 搜索区
└─ 苏中目的地 Chip（仅 OPEN）
└─ 推荐楼层 / 攻略入口
└─ 页脚
```

**Banner 区信息结构**

| 元素 | 说明 |
|------|------|
| 主视觉图 | 运营配置图；`alt` 用标题或「活动宣传」 |
| 整卡热区 | 整图可点（不必单独按钮） |
| 指示点 | 仅 ≥2 条时显示；当前帧高亮（Brand） |
| 左右切换 | ≥2 条：桌面箭头可选；移动端触滑为主 |
| 「活动」Caption | **可选，本包默认不做**；不做「广告/赞助」刺眼角标 |

**条数规则**

| 启用且合法条数 | 表现 |
|----------------|------|
| 0 | **隐藏** Banner 区；搜索区紧接顶栏；首页其余正常 |
| 1 | **静帧**；无指示点、无自动切 |
| ≥2 | **轮播**：约 5s 自动下一张；可手动；悬停/聚焦/`prefers-reduced-motion` 时暂停自动 |

**展示集合（前端过滤提醒）**

- 只展示 `enabled` 且（`ALL` **或** `CITY` 且该市 OPEN）。  
- **ALL 不受目的地 Chip / URL 市参影响**（产品 Q3）。  
- 按 sort **升序**（越小越前）；轮播起始为排序最前一条（对 C-Ad3）。

**操作与反馈**

| 操作 | 反馈 |
|------|------|
| 点击 Banner（站内路径） | 同标签页进入目标 |
| 点击 Banner（http/https） | 新标签页打开；`noopener noreferrer` |
| 点指示点 / 滑切 | 切换当前帧；重置自动播放计时 |
| 无 Banner | 无操作；不展示空槽 |

**状态增量**

| 态 | 表现 |
|----|------|
| 默认 | 按条数规则展示或隐藏 |
| loading | Banner 区可选极短骨架（或与首屏一并）；避免长时间空白跳动，优先稳定高度或加载完再挂载 |
| empty（0 条启用） | **等价隐藏**；不显示「暂无广告」类文案（避免干扰主路径） |
| error | Banner 接口失败：**静默隐藏**该区（不挡搜索/意向主路径）；可选控制台日志；不整页报错 |
| 无权限 | N/A（公开） |
| 校验失败 | N/A |
| 窄屏 | 满宽自适应比例；触滑；指示点保留 |

**文案禁区：** 无支付/买位/钱包 CTA；不出现强制「广告」「赞助」角标；意向相关文案本包不改。
