## 2. 主流程（给线框）

### F1 运营开通一城（主任务）

```
开城列表 → 选市 → 单市页（状态 + checklist + N/M 计数）
  → 未达标：开通按钮 disabled + 缺项提示
  → 达标：点「开通」→ 确认 → 状态 OPEN → 成功反馈
  → 已 OPEN：可「关闭开通」→ 确认 → CLOSED
```

**单市页必显：**

| 区块 | 内容 |
|------|------|
| 头 | 省 / 市名；状态徽章 OPEN / CLOSED（或未开通） |
| 计数 | 上架可意向店 **当前/N**；关联攻略 **当前/M**（达标绿/未达标警示） |
| Checklist | 5 项勾选：①目的地数据齐 ②供给达标 ③攻略达标 ④客服覆盖已说明 ⑤测数/脏数据已清理 |
| 主 CTA | 「开通此市」— 仅 checklist 全勾且计数达标可点；否则禁用并列出缺项 |
| 次 CTA | 已 OPEN 时「关闭开通」（二次确认） |

文案建议：开通成功「该市已对客可见」；关闭「门户将不再展示该目的地」。

### F2 游客逛已开通市（沿用一期，微调）

```
首页 Chip（仅 OPEN）或列表筛市 → 列表 → 详情 → 提交意向
```

无支付 CTA；意向流程与一期一致。

### F3 游客碰未开通 / 已关闭

| 场景 | 界面要点 |
|------|----------|
| 选未开通市（若筛里露出）或深链带未开市 | **空态**：「该目的地暂未开通」+ 引导「看看已开通目的地」或回首页 Chip |
| CLOSED 市店直链 | 与下架一致：不可订、无提交意向主 CTA；可留客服电话（沿用站配） |
| 首页 Chip | **不要**展示 CLOSED / 未开通市 |

空态勿写「上架」对客（UF-1）；勿出现支付相关词。

### F4 运营看板

```
看板 → 时间窗（近7天 / 近30天 / 全部）→ 市筛选或「全部」
  → 表/卡：意向数 | 已确认 | 已入住
  → 可选「导出」
```

只读；无钻进改单（改单仍走现有意向列表）。

## 3. 状态一览（UI 要画清）

| 对象 | 状态 | 对客 | 运营 |
|------|------|------|------|
| 市 | 未开通 / CLOSED | 不可选为目的地；直链店不可订 | 可补数据、开通 |
| 市 | OPEN | Chip/筛可选；列表露出上架店 | 可关闭 |
| 房源 | 上架且市 OPEN | 可意向 | — |
| 房源 | 市 CLOSED | 直链不可订 | 后台仍可编 |

---

## 4. 信息结构提示（非视觉终稿）

- 开城列表：市名、状态、供给数、攻略数、最近操作时间。  
- 门户 Chip：市名即可；数量角标可选不做。  
- 看板：市维度一行三数；合计行置顶。  
- 禁：支付进度条、定金金额、锁房日历。

---

## 5. 文案禁区（跨期硬锁）

- CHECKED_IN 仅「已入住」；禁已订立/已落实/已落地/已成交/已达成。  
- 对客勿写「上架」；运营后台可用「上架」。  
- 无「去支付 / 定金 / 钱包」。

---

## 6. UI 交付期望（给项目经理）

1. 开城列表 + 单市开通页（含 checklist / 禁用态 / 确认）。

3. 门户：Chip 规则说明 + 未开通空态 + CLOSED 直链不可订态。  
4. 关键说明：主路径一次任务；空态去哪。

画完产品按 C01–C10 / 空态抽检口径补验收即可排前端。
