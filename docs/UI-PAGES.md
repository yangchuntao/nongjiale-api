# 农家乐旅游网站 — 页面 UI 规格（线框级）

> 维护：资深UI/UE设计师 · 信息层级 / 区块结构 / 组件 / 窄屏与状态  
> 交互与文案以 [DESIGN.md](./DESIGN.md) 为准；视觉令牌以 [UI-TOKENS.md](./UI-TOKENS.md) 为准  
> 更新：2026-10-14（上海）

说明：下列为**线框级结构**（区块自上而下），非像素稿。前端按组件库实现；有 Figma 后再链到本文。

## A. 门户

### A0. 全局壳

```
[Logo/站名]  [搜索框]  [登录 / 已登录手机号]
———————— 主导航：首页 | 地区 | 资讯 ————————
[主内容]
———————— 页脚：联系电话(配置) · 简短说明 ————————
```

- Logo 点回首页；未定品牌名时用「农家乐预订」占位。  
- 窄屏：搜索可进独立页或顶栏展开；导航收汉堡或底部 Tab（一期用顶栏折叠即可）。

### A1. 首页 `/`

**信息层级**：① 搜索/地区入口 → ② 热门农家乐 → ③ 专题 → ④ 资讯摘要  

| 区块 | 内容 | 组件 |
|------|------|------|
| Hero / 搜索 | 关键词、主按钮「搜索」 | Input + Button primary |
| 地区入口 | 横向 chips 或网格（长三角种子） | Tag / Link |
| 热门 | 卡片栅格：封面、名、起价、销量/评 | HomestayCard |
| 专题 | 横滑或 2 列图文 | TopicCard |
| 资讯 | 标题列表 3～5 条 | List item |

**状态**：加载骨架；热门空 →「暂无推荐」；错误 → 可重试。

### A2. 列表 `/regions/:slug` · `/search?q=`

```
[筛选条：价格/排序]     共 N 家
[卡片] [卡片] [卡片]
…
[分页]
```

**卡片信息序**：封面 → 名称 → 起价（强调）→ 房型摘要 → 销量/评论数  

**状态**：空 →「没有匹配的上架房源」（对齐 T7）；加载；错误可重试。窄屏单列。

### A3. 详情 `/homestays/:id`

```
[图集主图 + 缩略]
[名称] [上架态]
[价格档：平日/周末…]
[房型表]
[设施] [须知]
[评价摘要]
[附近推荐]
—— 宽屏：右侧或底部 CTA 组 ——
—— 窄屏：吸底 [在线预约][电话预订][在线咨询] ——
```

**层级**：名称与起价最强；须知次之；附近最弱。  

**下架**：主文案「该农家乐暂不可预订」；预约 CTA disabled；电话仍可用（客服号）。  

**三 CTA**：主按钮样式给「在线预约」；电话 / 咨询为 secondary 或 text+icon，动词不可混用。

### A4. 登录 `/login`

居中卡片：标题「登录」→ 手机号/账号字段（跟后端方案）→ 主按钮「登录」→ 错误文案在字段下。  
成功后回 `redirect`（预订表单或留言）。

### A5. 预订表单 `/homestays/:id/book`

```
[房源摘要条：名 + 封面小图]
到店 | 离店
人数 | 出行方式
联系人 | 手机（预填可改）
[提交预订意向]  [返回]
```

字段错误贴字段下方（红文案）。提交中按钮 loading、防重复。窄屏单列。

### A6. 成功页 `/booking/success`

```
✓ 预订意向已提交
单号：xxxx（等宽或加粗）
请联系 [13651814168]（tel: 链接样式）
[返回首页]
```

**禁止**出现「查看我的订单」。电话必须可点、对比清晰。

### A7. 咨询留言

同预订：摘要条 + 多行留言 + 联系方式预填 +「提交留言」。成功提示含电话导向。

### A8. 资讯

列表：标题、日期；详情：标题、正文、相关推荐。404 独立页文案「内容不存在」。

## B. 管理端

### B0. 布局

```
[侧栏导航] | [顶栏：账号/角色]
           | [页面标题 + 主操作]
           | [内容区：表格/表单]
```

客服侧栏**无**「房源编辑」「账号」写入口（只读房源可进查看）。运营全开。

### B1. 工作台

数字卡片：待跟进意向、待处理留言；点进对应列表。空态：「暂无待办」。

### B2. 意向列表 / 详情

列表：筛状态、关键词、分页；列：单号、房源、游客、到店、状态、更新时间。  

详情：基本信息 → **状态操作**（确认/改期/关闭，二次确认对话框）→ **备注时间线**（上新下旧）。  
409：Toast「数据已更新，请刷新后重试」+ 刷新按钮。

### B3. 留言

与意向类似；标签区分「意向 / 留言」。处理动作：已处理 + 备注。

### B4. 房源编辑（运营）

分区：基础信息 | 价格档/房型 | 图集 | 上下架开关。客服进入为只读表单（无保存）。

### B5. 内容 / 地区 / 推荐 / 账号

标准后台表单 + 表格；排序用数字或拖拽（一期数字即可）。无权限页：插图或空态 +「无访问权限」。

## C. 跨页 UI 状态清单（验收用）

| 状态 | 视觉要求 |
|------|----------|
| 加载 | Skeleton 或 Spinner，保留页面骨架，不白屏 |
| 空 | 短文案 + 可选引导操作（回首页/改搜索） |
| 错误 | 说明 +「重试」；不弹裸技术栈 |
| 校验失败 | 字段下红字；焦点落到首个错误字段 |
| 无权限 | 独立说明，非 404 混淆 |
| 窄屏 | 详情 CTA 吸底不挡关键价格信息；可上滑看须知 |
