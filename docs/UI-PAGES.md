## A. 门户 `apps/portal`

### A0. 全局壳

```
[Logo/站名]  [搜索框]  [登录 | 我的意向 / 已登录手机号]
———————— 主导航：首页 | 地区 | 攻略/资讯 ————————
[主内容]
———————— 页脚：联系电话(配置) · 商家入驻 · 关于/帮助 ————————
```

- Logo 点回首页；未定品牌名时用「农家乐预订」占位。  
- 窄屏：搜索可展开；导航顶栏折叠。

### A1. 首页 `/`

**信息层级**：① 搜索/地区 → ② 推荐楼层 → ③ 攻略入口 → ④ 信任条 + 客服电话  

| 区块 | 内容 | 组件 |
|------|------|------|
| Hero / 搜索 | 关键词、主按钮「搜索」 | Input + Button primary |
| 地区入口 | chips / 网格（长三角种子） | Tag / Link |
| 推荐 | 卡片：封面、名、起价、销量/评 | HomestayCard |
| 攻略入口 | 标题列表 3～5 条或入口卡 | List / Card |
| 信任条 | 短卖点（人工确认档期等） | Banner / Text |
| 电话 | 配置号，可 `tel:` | Link |

**状态**：加载骨架；推荐空 →「暂无推荐」；错误可重试。**不做**专题横滑频道。

### A2. 列表 `/regions/:slug` · `/search?q=`

```
[筛选：下级地区 / 特色 / 价格]  [排序：综合|价格|销量]  共 N 家
[卡片栅格]
[分页]
```

**卡片序**：封面 → 名称 → 起价（强调）→ 特色/房型摘要 → 销量/评  

**状态**：空 →「没有匹配的上架房源」；加载；错误可重试。窄屏单列。

### A3. 详情 `/homestays/:id`

```
[图集主图 + 缩略]
[名称] [上架态]
[地址] [本店电话 tel:]
[套餐/价格档说明]
[须知] [交通] [周边]
[评论只读]
[附近推荐]
—— 窄屏吸底：[立即预订][电话预订][在线咨询] ——
```

**下架**：文案「该农家乐暂不可预订」；立即预订 disabled；电话仍可用（客服号）。  
**主按钮**给「立即预订」；电话/咨询 secondary。

### A4. 登录 / 注册 `/login` · `/register`

居中卡片：手机号 + 密码 → 主按钮；链到注册/登录互跳。成功回 `redirect`。

### A5. 意向表 `/homestays/:id/book`

```
[房源摘要条]
到店 | 离店 | 人数
联系人 | 手机（预填可改）
[提交预订意向] [返回]
```

字段错红字贴下方；提交中 loading 防重。

### A6. 成功页 `/booking/success`

```
✓ 预订意向已提交
单号：xxxx
意向不等于已锁房；客服将确认档期
请联系 [{contactPhone}]（tel:）
[返回首页] [我的意向]
```

禁止支付入口；可进「我的意向」。

### A7. 我的意向 `/me/intents`

列表：单号、房源名、到店、状态、提交时间 → 点进只读详情。  
空态引导回首页。无取消/支付按钮。

### A8. 咨询留言

摘要条 + 多行留言 + 联系方式 +「提交留言」。成功含电话导向。

### A9. 资讯 / 攻略

列表：标题、日期；详情：标题、正文、相关。404：「内容不存在」。

### A10. 商家入驻申请 `/merchant/apply`

表单：主体名称、联系人、手机、拟营门店名/地区、说明、证照上传位 →「提交入驻申请」。  
成功：「已提交，等待审核」。

## B. 运营管理端 `apps/admin`

### B0. 布局

```
[侧栏] | [顶栏：账号/角色]
       | [标题 + 主操作]
       | [表格/表单]
```

| 角色 | 侧栏可见 |
|------|----------|
| 运营 | 工作台、意向、留言、入驻审、上下架审、房源、资讯、推荐、商家账号、站点配置 |
| 客服 | 工作台、意向、留言、房源（只读） |

### B1. 工作台

数字卡：待跟进意向、待审入驻、待审上下架（客服只见意向/留言）。空：「暂无待办」。

### B2. 意向 / 留言

列表筛状态+关键词；详情：状态操作（二次确认）+ 备注时间线。  
409：Toast「数据已更新，请刷新」+ 刷新。

### B3. 入驻审核

队列：待审优先；详情：资料只读 + 通过 / 驳回（原因必填）。通过成功提示「已开通商家账号」。

### B4. 上下架审核

队列：门店、申请类型（上/下架）、申请人、时间；通过/驳回（原因）。可通过后预览门户态说明。

### B5. 房源 / 资讯 / 推荐 / 商家账号 / 站点配置

标准后台表单+表格。站点配置：站名、主色（色板或 hex）、客服电话。无权限页勿与 404 混淆。

## C. 商家端 `apps/merchant`

### C0. 布局

```
[侧栏：工作台 | 门店 | 上下架申请 | 意向(只读) | 账号]
| [顶栏：主体名 / 退出]
| [内容]
```

视觉跟 admin 同一套 Element Plus 映射，**品牌条可标「商家中心」**以免与运营端混淆。

### C1. 工作台

本店数量、待审申请数、新意向数（点进只读列表）。无结算卡片。

### C2. 门店列表 / 编辑

列表列：店名、地区、对客状态、申请态。  
编辑分区：基础 | 图集 | 套餐/价格档 | 标签 | 交通/须知/周边。  
底栏：「保存」；上架/下架走「提交申请」入口（非直接开关）。

### C3. 上下架申请

表单：选择门店、类型（上架/下架）、说明 → 提交。  
列表：历史申请 + 状态 + 驳回原因。待审中禁用同店同向重复提交。

### C4. 意向只读

列表/详情无状态变更、无备注输入；手机脱敏；角标「只读」。

### C5. 登录 / 改密

与运营端视觉区分文案「商家登录」；停用账号明确「账号已停用，请联系运营」。

## D. 跨页 UI 状态清单（验收用）

| 状态 | 视觉要求 |
|------|----------|
| 加载 | Skeleton / Spinner，保留骨架 |
| 空 | 短文案 + 引导 |
| 错误 | 说明 +「重试」 |
| 校验失败 | 字段下红字；焦点首错 |
| 无权限 | 独立说明，非 404 |
| 窄屏 | 详情 CTA 吸底 |
| 脱敏 | 商家端手机中间四位 `*` |
