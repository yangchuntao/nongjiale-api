## 门禁总则

- 前置：环境可访问；种子/测试账号齐（游客、运营、客服、商家 A、商家 B）  
- 通过条件：下表每条「可观察结果」成立；**明确不做**项标「不测」且产品抽检无漂移  
- 配置：站名/主色/客服电话正式值到位后，A-CFG 必须重跑；未到位前可用占位配置，终验前补齐

## A · 门户游客

| ID | 前置 | 操作 | 可观察结果 |
|----|------|------|------------|
| A0 | 未登录 | 详情点「立即预订」 | 进入登录；登录成功后回跳该房源预订表单 |
| A1 | 已登录 + 上架可订门店 | 提交合法意向（日期合法、人数≥1） | 成功页：单号 + 可拨打**配置客服电话**；库中待跟进且含 userId；文案不暗示已锁房/已付款 |
| A1b | 无登录态 | 调提交意向接口 | 401，不入库 |
| A2 | 已登录 + 同用户同门店同到店日已有单 | 再提交/弱网重试 | 不新增；返回已有单 |
| A3 | 门店下架或未审上架 | 打开详情或提交 | 详情 **410**；再提交意向 **409** |
| A4 | 已登录 | 非法日期（离店≤到店）或人数 0 | 字段错误，不入库 |
| A5 | 已登录 | 打开「我的意向」 | 只见本人单据；可见状态；**无**取消/改状态入口 |
| A6 | 列表无结果 | 打开列表 | 空态，非报错页 |
| A7 | 任意 | 走攻略/资讯列表→详情 | 可打开运营已发布内容 |
| A8 | 未登录 | 点「在线咨询」 | 先登录再回跳；已登录合法留言进待跟进 |
| A9 | 访客 | 提交商家入驻申请（必填齐）；开通前调商家登录 | 申请进入待审；开通前商家登录 **401**；申请人**未**自动获得商家权限 |

## B · 运营 / 客服

| ID | 前置 | 操作 | 可观察结果 |
|----|------|------|------------|
| B1 | 运营 | 通过入驻申请 | 商家账号可用且绑定该主体；驳回须原因且可再提 |
| B2 | 运营 | 审核商家上架申请通过 | 门店对游客可订；驳回后仍不可订且原因可见 |
| B3 | 运营 | 审核下架申请通过 | 门店对游客不可订 |
| B4 | 运营/客服 | 意向确认 + 备注 | 状态已确认；备注时间线可见 |
| B5 | 客服 | 尝试入驻审 / 管商家账号 / 改站点配置 | **无权限**，数据不变 |
| B6 | 客服 | 尝试改房源「首页推荐」标记/排序，或改归属 | **无权限**；推荐楼层仅运营可改房源推荐字段（**无**独立推荐位 CRUD） |
| B7 | 运营 | 改站点客服电话并保存 | 成功页/`tel:` 展示新号码（配置生效） |
| B8 | 运营 | 上下架申请队列 | 仅运营可审；客服不可审（默认） |

## C · 商家端（第三端）

| ID | 前置 | 操作 | 可观察结果 |
|----|------|------|------------|
| C1 | 商家 A 已入驻 | 登录商家端 | 只见本主体门店；不见商家 B 门店 |
| C2 | 商家 A | 改自家门店图文/套餐并保存 | 后台资料更新；**未**经上架审则游客仍不可订（若原为下架） |
| C3 | 商家 A + 门店下架 | 提交上架申请 | 进入运营待审；游客端仍不可订直至 B2 |
| C4 | 商家 A | 打开意向列表 | **只读**本店意向；手机脱敏；**无**改状态/写跟进入口 |
| C5 | 商家 A | 调改意向状态或写跟进接口 | 拒绝（403/业务错），状态不变 |
| C6 | 商家 A | 尝试编辑商家 B 门店或审入驻 | 拒绝，数据不变 |
| C7 | 商家 A | 商家端是否出现支付/结算/提现入口 | **无**（范围抽检） |
