## 状态与「后端可测?」说明

| 状态 | 含义 |
|------|------|
| 待测 | 未执行（本版默认） |
| PASS / FAIL | 已执行结论 |
| 阻塞 | 依赖未就绪（如契约未出、扬州补数未齐） |
| 不测 | 明确不做或抽检项 |

| 后端可测? | 含义 |
|-----------|------|
| **是** | 契约已落地且 main 有对应接口，可不靠 UI 先 API 验 |
| **部分** | 可读现有接口抽检，或契约未全；UI/文案/计数展示需联调 |
| **否** | 待开城写接口或纯 UI 才能完整验（本版多数为否/部分） |

**方式：** API / UI / 人工（可组合）。

### 已拍参数（验收必盯）

| 口径 | 验收落点 |
|------|----------|
| 首开城市=扬州；苏中已 OPEN 市保持 | C02 / C06 / 补数前置 |
| N=5、M=1；checklist 五项全勾才可开通 | C01 / C10 |
| 未达标禁止开通（无 force-open） | C01 |
| CLOSED 市店直链：对客不可订，体验对齐下架（**410** 类） | C05 |
| 推荐仅所属市 OPEN 时对客首页展示 | C06 |
| 无支付/定金/钱包 CTA；已入住文案不变；商家意向只读 | C08 |
| 对客空态勿写「上架」（UF-1） | C04 / C05 / C08 |

### HTTP 语义（沿用 MVP-0；开城新增码待契约）

| 码 | 用途（已定 / 沿用） |
|----|---------------------|
| **410** | 下架详情；对不可订店提交意向；**CLOSED 市店直链详情默认同此体验**（产品 §3.4） |
| **409** | 业务冲突（状态机非法迁移、乐观锁、重复开通等——开城具体冲突码 **待契约**） |
| **400** | 校验失败 |
| **401** / **403** / **404** | 未登录 / 无角色或越权 / 资源不存在 |

> **待契约说明：** 下表「接口路径」凡标「待契约」者均为推测占位（如 `POST /api/admin/cities/{id}/open`）。断言以「可观察结果」列为准；BE 设计出稿后统一改路径与 HTTP 列，并将「后端可测?」升为是/部分。
