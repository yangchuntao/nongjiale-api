## EXEC 锁（本版重要）

> **本版 v0.2.1：路径已按 api#22 Ready 回填（不变）；产品门禁 PASS ✓；老板 TECH 终验 ✓（web#11 + api#22 + api#23 已手合）；产品已放行可开业务码。仍不作为已授权执行清单。路径已回填 ≠ 已授权 EXEC。**

解锁 **EXEC / 正式跑测** 须同时满足：

1. **路径已回填**（已完成：对齐 api#22 Ready / BE 契约源；契约仍以 api#22 为准；Admin CRUD `/api/admin/banners`；启停 `POST /api/admin/banners/{id}/enable`、`POST /api/admin/banners/{id}/disable`；门户 `GET /api/home/banners`）；  
2. **产品门禁 PASS ✓**（已满足：web#11 + api#22；UI 门禁见 `GATE-UI-MVP-1.5-广告位-产品.md`）；  
3. **老板 TECH 终验 ✓**（已满足：web#11 + api#22 + api#23 已手合；产品已放行可开业务码）；  
4. **业务实现 PR 合入** + **运维滚测服 jar/静态（V5 + banners）**——**当前 EXEC 只等此项**；完成后才可对 Banner API **正式开跑并下 PASS/FAIL**。

此前：可做用例评审、测服账号/扬州·南通状态确认、线框对照、契约对照；**不可**对未合入 / 未滚测服的 Banner API 下 PASS，**不可**发版结论。
