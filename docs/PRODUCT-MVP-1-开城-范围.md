## 2. 范围

### 2.1 本次要做

| # | 能力 | 说明 |
|---|------|------|
| C1 | **开城 checklist（运营）** | 每城开通前勾选/记录：目的地数据齐、最低上架供给 N、攻略≥M、客服覆盖说明、测数/脏数据清理确认。未达标不可点「开通」或开通后标「带风险开通」（默认：**未达标禁止开通**，见待确认）。 |
| C2 | **region 开通配置** | 运营将某「市」设为 `OPEN` / `CLOSED`（或等价）；仅 `OPEN` 在门户目的地与列表默认可选。苏中一期已运营市保持 OPEN。 |
| C3 | **门户地理露出** | 首页目的地 Chip / 列表筛：按省→市（区可选）；游客选未开通市 → 明确「暂未开通」空态，**不串**其他市脏数据。 |
| C4 | **供给绑定地理** | 房源已有省市区；开城后列表/推荐仅展示**已开通市 + 上架可订**；商家入驻选址仍按现有，新区市开通后自然可露出。 |
| C5 | **攻略按城** | 攻略可关联市（或沿用现关联）；开通城至少可挂 M 篇（checklist）；未开通城攻略不对客主推。 |
| C6 | **种子指标看板（运营）** | 只读：按市（及合计）意向数 / 已确认数 / 已入住数（时间窗可选近 7/30 天）；可导出 CSV 等价即可。 |
| C7 | **关城** | 运营可将市设为 CLOSED：门户不再作为可选目的地；已上架店详情直链是否仍可打开见规则 §3。 |

## 3. 业务规则

1. **开通单位**：以**地级市**（或老板指定的同级行政区）为开通粒度；区县为筛选项，不单独「开城」。  
2. **OPEN 条件（默认）**：checklist 全勾 + 上架可意向店 ≥ **N** + 关联攻略 ≥ **M** 才允许设为 OPEN。  
3. **CLOSED**：从门户目的地/默认列表消失；已产生的意向与历史数据保留。  
4. **直链详情**：CLOSED 市的店 — **默认**返回不可订/410 类对客态（与下架一致体验），运营后台仍可编辑。  
5. **全国叙事**：首页可保留「全国」文案；可点目的地仅 OPEN 市。  
6. **推荐**：`homeRecommended` 仅在所属市 OPEN 时对客首页展示。  
7. **商家**：无新权限；只读意向不变；无支付字段。  
8. **测试数据**：开通前须确认该市无爬取脏数据对客可见（checklist 项）。

## 4. 用户流程（摘要）

### 4.1 运营开通一城

1. 进入「开城/目的地」管理 → 选市。  
2. 查看 checklist 与当前供给/攻略计数。  
3. 补数据至达标 → 点「开通」。  
4. 门户该市 Chip/筛出现；列表可见该市上架店。

### 4.2 游客逛新区

1. 首页选 OPEN 市 Chip 或列表筛市。  
2. 浏览/详情/提交意向（一期流程不变，无支付）。  
3. 选未开通市 → 空态说明，引导回已开通或「找农家乐」全部已开通。

### 4.3 运营看看板

1. 打开指标看板 → 选市或全部 → 见意向/确认/入住计数。  
2. 可选导出。

## 5. 验收标准（可测）

前置：测服有苏中 OPEN 市；扬州可配供给/攻略达 N/M 后验收开通。

| ID | 前置 | 操作 | 可观察结果 |
|----|------|------|------------|
| C01 | 某市未达标 | 运营尝试开通 | 拒绝或不可点，并提示缺项（N/M/checklist） |
| C02 | 某市达标 | 运营开通 | 状态 OPEN；门户目的地出现该市 |
| C03 | 市已 OPEN，有上架店 | 游客选该市 | 列表仅该市（或含该市）上架可意向店；可进详情提交意向 |
| C04 | 市未 OPEN | 游客选/搜该市 | 「暂未开通」类空态；不出现他市店冒充 |
| C05 | 市 OPEN 后关为 CLOSED | 游客再选 | 目的地不可选或空态；直链详情按 §3.4 |
| C06 | 多市 OPEN | 列表筛省市区 | 筛市有效；推荐仅 OPEN 市 |
| C07 | 有意向数据 | 打开看板 | 按市可见意向/已确认/已入住（或合计+下钻） |
| C08 | — | 巡检三端 | **无**支付/定金/钱包 CTA；已入住文案不变；商家意向只读 |
| C09 | 攻略关联 OPEN 市 | 门户攻略入口 | 可见该市攻略；未开通市不主推 |
| C10 | checklist | 开通页 | 可见五项勾选与 N/M 实时计数 |
