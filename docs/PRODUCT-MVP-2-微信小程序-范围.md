# MVP-2 微信小程序 · 详细范围与验收

> 资深产品经理 · 2026-10-18  
> 依据：老板拍 **W-B**（W-A 最小对客漏斗 + 首页 Banner + 攻略只读）；分期见 `PRODUCT-MVP-分期-已拍.md`。  
> **插在广告位后、定金前。** 无支付；不改意向状态机；CHECKED_IN 仍「已入住」；商家/运营不做小程序端。

---

## 1. 问题 / 目标用户 / 一次结果

| 项 | 内容 |
|----|------|
| 问题 | 游客多在微信内发现与转化；仅 Web 门户分享弱，社群/本地获客难落到同一意向成交。 |
| 目标用户 | **游客（对客）**：微信内找 OPEN 市农家乐、看详情与攻略、提交意向、查自己的单。 |
| 非本包用户 | **商家 / 运营**：继续用现有 Web；**不做**商家端小程序、**不做**运营后台小程序。 |
| **本包一次结果** | 游客用微信打开小程序，完成「首页（含 Banner）→ 找店/攻略 → 详情 → 登录 → 提交意向 → 我的意向」，并可分享到门店详情；供给与 OPEN 市、Banner、攻略、意向状态机与 Web **同一套口径**；**全端无支付**。 |

## 2. 范围

### 2.1 本次要做（W-B）

| # | 能力 | 说明 |
|---|------|------|
| W1 | **微信登录** | 微信授权登录；绑定/补全手机号（实现工程定）。**账号与 Web 打通**（同一用户主体；同人「我的意向」两端可见，打通字段以手机号或统一 userId 为准，工程定一种并写清）。 |
| W2 | **首页** | 简版首页：Banner 区（规则对齐 MVP-1.5）、目的地/找店入口、攻略入口、客服电话。 |
| W3 | **首页 Banner** | 复用运营已配 Banner；规则同 Web：仅启用；`sortOrder` 越小越前；`ALL` 不受 Chip；`CITY` 仅 OPEN；0 条则隐藏区不挡主路径；点击站内同页栈 / 外链按小程序外链规范（工程+UI 定，产品要求可到达所配目标）。 |
| W4 | **找店列表** | 仅 **OPEN** 市上架供给；筛选项取 Web 合理子集（至少市 + 关键词或等价）。 |
| W5 | **门店详情** | 图文、电话、套餐/须知摘要、**提交意向**；支持从分享卡片进入。 |
| W6 | **提交意向** | 须登录；成功页单号 + 客服电话；文案含 **意向 ≠ 已锁房**。 |
| W7 | **我的意向** | 只读列表 + 详情；状态展示与 Web 一致（含 CHECKED_IN=「已入住」）。 |
| W8 | **攻略只读** | 攻略列表 + 详情；无问答/专题等；内容来自现有运营攻略。 |
| W9 | **分享到门店** | 可分享卡片落到门店详情（获客刚需）。 |
| W10 | **硬锁巡检** | 无支付/买位/钱包 CTA；不改意向状态机码；商家/运营配置能力不可达。 |

## 3. 业务规则

1. **投放与配置**：Banner、攻略、开城、意向跟进仍仅运营 Web；小程序只读消费。  
2. **地理**：仅展示 **OPEN** 市上架店；CLOSED 不串脏数据。  
3. **Banner**：对齐 MVP-1.5（ALL / CITY+OPEN / 启停即时 / 排序越小越前 / 无支付买位）。  
4. **账号打通**：小程序登录用户与 Web 用户同一主体；未打通前不得假装「已同步意向」。  
5. **意向**：规则、状态码、文案与 Web 一致；商家意向只读不在本包。  
6. **分享**：门店详情可被分享进入；无效/下架店按 Web 等价失败提示。  
7. **硬锁**：无支付；CHECKED_IN=「已入住」；禁已落实/已落地/已订立/已成交/已达成。

## 4. 用户流程（摘要）

1. 打开小程序首页 → 见 Banner（若有）/ 进找店或攻略。  
2. 列表选店 → 详情 →（未登录则登录）提交意向 → 成功页。  
3. 「我的」看意向只读。  
4. 分享门店卡片 → 好友打开落详情。

## 5. 验收标准（可测）· C-MP1～C-MP8

前置：测服有至少一市 OPEN 上架店、可用攻略、可配 Banner；小程序开发版/体验版可开；客服电话已配置；南通等 CLOSED 市可对照。

| ID | 前置 | 操作 | 可观察结果 |
|----|------|------|------------|
| **C-MP1** | 未登录 | 找店→详情→提交意向 | 要求登录；登录后可完成提交 |
| **C-MP2** | 已登录 + 可订店 | 提交意向 | 得单号；成功页有客服电话；含非锁房文案；「我的意向」可见 |
| **C-MP3** | 有 OPEN/CLOSED 市 | 列表/目的地 | 仅见 OPEN 供给；CLOSED 不串脏 |
| **C-MP4** | 运营已配启用 ALL Banner | 打开首页 | 可见 Banner；点击可达所配链接；停用后刷新不再展示 |
| **C-MP5** | ≥2 条启用、排序不同 | 打开首页 | 展示/轮播起始序与 `sortOrder` 越小越前一致 |
| **C-MP6** | 有已发布攻略 | 打开攻略列表/详情 | 可阅读；无问答/专题等入口 |
| **C-MP7** | 可订店 | 分享门店卡片并打开 | 落到该店详情 |
| **C-MP8** | — | 全路径巡检 | **无**支付/定金/钱包；无商家/运营配置入口；CHECKED_IN 仅「已入住」 |
