## 状态说明

| 状态 | 含义 |
|------|------|
| 待测 | 未执行（本版默认） |
| PASS / FAIL | 已执行结论 |
| 阻塞 | 依赖未就绪（UI/TECH 未出、实现未合入、测服小程序未接入） |
| 不测 | 明确不做 |

| 后端可测? | 含义 |
|-----------|------|
| **是** | 沿用已有 Web 对客/探活接口，可不靠小程序 UI |
| **部分** | 复用已知 Web API 可抽检数据口径；小程序页/登录/分享仍依赖 UI 或待 TECH 路径 |
| **否** | 纯小程序 UI / 微信能力才能完整验；或路径仍「待 TECH」 |

## EXEC 锁（本版重要）

> **本版 v0.1：EXEC 未解锁。** 产品范围已合入（api#28 / PRODUCT-MVP-2）；**不可**当作已授权执行清单。

解锁 **EXEC / 正式跑测** 须同时满足：

1. **UI 门禁 PASS**（小程序 IA：首页 Banner / 找店 / 详情 / 攻略 / 意向 / 登录 / 分享卡片）；  
2. **TECH Ready**（微信登录与 Web 账号打通方案写入 TECH；小程序路由与关键 API 路径回填；外链 Banner 打开方式定稿）；  
3. **实现合入**（小程序工程 + 所需后端登录/打通）；  
4. **测服小程序接入**（AppID、合法域名、开发版/体验版可开；本包测服现包维持策略由运维执行）。

此前：可做用例评审、测服 OPEN/CLOSED/Banner/攻略数据确认、与 Web API 对照抽检（S1 中标「是」项）；**不可**对未定路径的小程序登录/分享下 PASS，**不可**发版结论。
