# 农家乐旅游网站 — 设计说明（U1）

> 维护：资深UI/UE设计师 · 流程 / 页面清单 / 文案与状态 / 前端注意点
> UI 视觉与线框：[UI-TOKENS.md](./UI-TOKENS.md) · [UI-PAGES.md](./UI-PAGES.md)  
> 对齐：P1 终稿（方案 A · 必须登录 · 无我的订单 · 成功页 `tel:13651814168`）  
> 更新：2026-10-14（上海）· 联调有改动先改本文再同步项目经理

## 1. 用户与主任务

| 角色 | 主任务 | 入口 | 完成出口 |
|------|--------|------|----------|
| 游客 | 提交预订意向 | 门户首页 / 地区 / 搜索 | 成功页（单号 + 电话） |
| 运营 / 客服 | 跟进意向与留言；运营维护房源与内容 | 管理端登录 | 状态已更新 / 内容已发布 |

一期**一次只服务一个主要任务**：游客「提交预订意向」。不做：支付、我的订单、商家端、地图。

## 2. 门户主流程

1. 发现（首页地区 / 热门 / 专题 / 搜索）
2. 列表筛选
3. 详情（价格档、房型、设施、须知、评价、附近）
4. CTA 三选一：
   - **在线预约** →（未登录则登录并回跳）→ 预订表单 → 成功页
   - **电话预订** → `tel:`（号来自配置 `contactPhone`，默认 13651814168）
   - **在线咨询** →（未登录则登录并回跳）→ 留言表单 → 成功提示
5. 成功页：单号 +「请联系」+ 可拨打电话；**无「查看订单」**

## 3. 门户页面清单

| 页面 | 用户看到 | 可操作 | 操作后反馈 | 必做状态 |
|------|----------|--------|------------|----------|
| 首页 | 地区、热门、专题、资讯入口 | 进列表 / 详情 / 搜索 | 跳转 | 加载 / 空推荐 / 错误可重试 |
| 地区列表 / 搜索 | 卡片：名、起价、房型摘要、销量/评 | 筛、排、进详情 | 列表刷新 | 加载 / **空态** / 错误 / 窄屏 |
| 详情 | 图集、价格档、房型、设施、须知、评价、附近；底栏三 CTA | 在线预约 / 电话预订 / 在线咨询 | 预约进表单或先登录；电话拨号；咨询进留言 | 加载 / **下架不可订** / 错误 / 窄屏 CTA 吸底 |
| 登录 | 手机号等方式（跟后端认证） | 登录、返回 | 成功 → `redirect` 原预订/留言页 | 校验失败 / 错误 |
| 预订表单 | 到/离店、人数、出行方式、联系人、手机（可预填，可改） | 提交、返回详情 | 字段校验；成功进成功页；下架/401 明确提示 | 校验失败 / 提交中防重 / 失败可重试 / 无登录回登录 |
| 成功页 | **单号** + 「请联系」+ **可点拨电话** | 回首页、再拨电话 | — | 无「查看订单」入口 |
| 咨询留言 | 房源上下文 + 留言 + 联系方式预填 | 提交 | 「留言已提交…」+ 同电话导向 | 同登录 / 校验 / 防重 |
| 资讯列表 / 详情 | 标题、正文、相关 | 返回 | — | 加载 / 空 / 404 |

**不做页**：我的订单、支付、地图、商家端。

## 4. 管理端流程与页面

**流程**：登录 → 工作台 → 意向/留言跟进 →（运营）房源与内容维护。

| 页面 | 要点 | 状态 |
|------|------|------|
| 登录 | 账号登录 | 校验 / 错误 |
| 工作台 | 待跟进意向数、留言数 | 加载 / 空 |
| 意向列表 / 详情 | 筛状态；`待跟进`→`已确认`/`已改期`/`已关闭`；备注时间线；改状态二次确认 | 空 / 无权限 / **409 冲突提示刷新** |
| 留言列表 / 详情 | 分栏或同队列标签；标记已处理 + 备注 | 同上 |
| 房源列表 / 编辑 | 上下架、价格档、房型、图集（**客服只读**） | 校验 / 保存中 / 无权限 |
| 内容 / 地区 / 推荐位 | 发布、排序、启用 | 草稿 / 已发布 / 空 |
| 账号 | 运营 / 客服角色 | 无权限 |

## 5. 文案要点

| 场景 | 文案 |
|------|------|
| 主提交按钮 | 「提交预订意向」（避免理解成已付款锁房） |
| 成功页 | 「预订意向已提交（单号 xxx）。请联系 13651814168」 |
| 下架 | 「该农家乐暂不可预订」 |
| 留言成功 | 「留言已提交，我们会尽快联系。如需电话请拨 13651814168」 |
| 三 CTA | 「在线预约」「电话预订」「在线咨询」— 动词区分，勿混用 |

电话展示一律走配置 `contactPhone`，勿多处写死不同号。

## 6. 键盘与无障碍

- 表单 Tab 序：日期 → 人数 → 出行 → 联系人 → 手机 → 提交；主按钮可 Enter
- 图 / icon 有替代文本
- 正文与背景对比跟项目设计令牌；品牌名 / 主色未定时用中性令牌占位

## 7. 给前端的实现注意

- 路由对齐 F1；未登录进 book / 咨询 → `/login?redirect=…`
- 成功页与留言成功提示的电话来自 `GET /api/config/public` 的 `contactPhone`
- 列表卡片、分页、空 / 错 / 载复用项目组件；窄屏详情主 CTA 吸底
- 提交按钮 loading + 防重复点击，对齐后端幂等
- 管理端改状态二次确认；409 时提示刷新后再操作

## 8. 与验收 / 测试对齐

覆盖产品验收 #0–#7 的界面表现；咨询留言对齐 T8/T8b。UI 未验证项（T0、T1 成功页、T7）等前端主路径联调后由测试执行。
