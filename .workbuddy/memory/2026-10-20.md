## 新增部署与使用文档（docs/DEPLOYMENT.md、docs/USER-GUIDE.md）

- 部署目标确认：用户有一台**百度云轻量应用服务器**，按 Ubuntu 22.04 / 2C2G / 单机部署（Nginx + API + MySQL 8 + Redis）写。
- `docs/DEPLOYMENT.md`：从空机到可访问，含控制台防火墙、swap、JDK 17、MySQL 8 建库与参数、Redis 口令、环境变量、systemd、Nginx 三种前端放法、HTTPS/备案/小程序域名、上线 checklist、备份回滚、13 条常见坑、CentOS 差异。
- `docs/USER-GUIDE.md`：三端操作教程（游客/商家/运营），含演示账号、意向状态机、开城五项条件、Banner/站点配置规则、错误码表、FAQ、本期不提供清单。
- 新增 `deploy/`：`api.env.example`、`nongjiale-api.service`、`nginx-nongjiale.conf`、`deploy.sh`（本机构建+上传+备份旧包+健康检查）、`backup-mysql.sh`（mysqldump gzip 保留 7 天）。两个脚本已过 `bash -n`。
- `README.md` 增加「文档导航」表，指向上述文档与接口索引。
- 关键事实（写文档时从代码核对，可复用）：
  - `application.yml` 默认 profile 是 `local`（H2 内存库），生产必须设 `SPRING_PROFILES_ACTIVE=mysql`，否则重启丢数据且不报错。
  - Redis 密码不在 yml 里，只能通过 `SPRING_DATA_REDIS_PASSWORD` 注入；漏配表现为缓存刷 `NOAUTH`，但登录仍可用。
  - CORS 由 `APP_CORS_ALLOWED_ORIGINS` 逗号分隔覆盖，默认只放行 localhost 三个端口。
  - 种子数据：扬州/泰州/南通为 OPEN，但 V3 只有 3 家店、唯一攻略挂在**省**级，不满足 N=5/M=1；关城后无法再开，需先补数。
  - 开城五项：①目的地手勾 ②供给≥5 实时计数 ③攻略≥1 实时计数 ④客服手勾 ⑤脏数据手勾；②③手改返回 400。
  - 令牌在进程内存、12h、重启失效 → 只能单实例部署。
