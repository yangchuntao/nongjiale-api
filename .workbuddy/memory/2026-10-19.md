## 接入 Swagger（springdoc-openapi 2.6.0）
- 依赖：`org.springdoc:springdoc-openapi-starter-webmvc-ui:2.6.0`（property `springdoc.version`），对齐 Boot 3.3.13。
- 新增 `config/OpenApiConfig.java`：OpenAPI 元信息（三端说明、信封、错误码、分页）+ 全局 `bearerAuth`（HTTP bearer，非 JWT）。安全方案常量 `OpenApiConfig.SECURITY_SCHEME_NAME`。
- 开关：`application.yml` 中 `springdoc.api-docs.enabled` / `springdoc.swagger-ui.enabled` 均取 `${OPENAPI_ENABLED:false}`；`application-local.yml` 显式打开。生产默认关闭。
- 注解：25 个业务 Controller + HealthController 加 `@Tag`/`@Operation`（69 个路由全覆盖）；需登录的类或方法加 `@SecurityRequirement(name="bearerAuth")`（54 个操作带鉴权）；63 个 DTO + ApiResponse/PageResult 加 `@Schema`。
- **坑**：泛型 record `ApiResponse<T>` / `PageResult<T>` 不能写 `@Schema(name=...)`，否则 springdoc 复用同一个 schema，所有接口 data 都指向同一个具体类型（曾出现 /api/stores 返回 MerchantStoreResponse）。去掉 name 后生成 120 个按具体类型命名的 schema。
- 验证：`/v3/api-docs` 60 paths / 69 operations / 26 tags / 120 schemas，全部有 summary 与 tag；`/swagger-ui.html` 200；`mvn test` 152 测试通过、覆盖率门禁通过。
- 文档：README 新增「在线接口文档（Swagger）」章节，docs/API-INDEX.md 增加在线版入口说明。
